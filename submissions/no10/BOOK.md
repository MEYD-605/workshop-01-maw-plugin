## บทที่ 1: เรียนรู้อะไรวันนี้ (What We Learned)
ในการเข้าร่วมกิจกรรม Workshop 01:
1. **การเขียนโครงสร้าง maw plugin**: ศึกษาและสร้างปลั๊กอินภายใต้ข้อกำหนดของระบบนิเวศ `maw-js` โดยใช้สัญญาระบบ `plugin.json` และการกำหนด `entry` เพื่อเรียกฟังก์ชันจากปลั๊กอิน
2. **การรันในโหมด Dual-Mode**: ออกแบบ `index.ts` ให้ยืดหยุ่น โดยสามารถประมวลผลได้สองส่วนคือ `Workshop SDK Mode` (รันคำสั่ง `.command()` ใน sandbox ของโรงเรียน) และ `Local CLI Context Mode` (รับสิทธิ์ควบคุมตรงผ่าน CLI แท้บน LXC container)
3. **การจัดการสิทธิ์และการสื่อสาร (Permissions & Surfaces)**: กำหนดความสามารถพิเศษใน `capabilities` เช่น `fs:read` และ `sdk:plugin` เพื่อให้ปลั๊กอินเข้าถึงและทำงานอย่างปลอดภัย และเปิดอินเทอร์เฟซ CLI ภายใต้ชื่อย่อ `no10` เพื่อเรียกใช้งานได้อย่างแม่นยำ

## บทที่ 3: Lessons Learned (บทเรียนที่ได้รับ)

1. **การตรวจสอบที่ลึกถึงแก่น (First-Principles Diagnostics)**: ปัญหาระบบค้างลูปบางประเภทอาจหลุดรอดการป้องกันของ Watchdog ไปได้ การใช้เครื่องมือระดับล่างอย่าง `ps aux` และ `tmux capture-pane` ช่วยวิเคราะห์และแก้ไขปัญหาได้อย่างทันท่วงที
2. **การระบุเป้าหมายกิ่ง Git ที่ต่างกัน (Target Repository Precision)**: บอทตัวอื่นพลาดเป้าในการ push เนื่องจากสับสนระหว่าง upstream และ fork การตรวจสอบ remote configuration ให้ชัดเจนทำให้เราสามารถผลักโค้ดขึ้น GitHub Fork และสร้าง Pull Request ได้อย่างแม่นยำ
