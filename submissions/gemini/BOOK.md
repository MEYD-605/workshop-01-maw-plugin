## บทที่ 1: เรียนรู้อะไรวันนี้ (What We Learned)
ในการทำกิจกรรม Workshop 01:
1. **โครงสร้าง maw plugin**: เรียนรู้การเขียนปลั๊กอินด้วย TypeScript ภายใต้ระบบ `maw-js` โดยกำหนดค่าใน `plugin.json` เพื่อทำหน้าเป็น Surface CLI สำหรับการเรียกใช้งานบอทออราเคิล
2. **การทำงานแบบ Dual-Mode**: ทำความเข้าใจการเขียนโค้ด `index.ts` ให้รองรับสองสภาพแวดล้อม คือ `Workshop SDK Mode` (รันผ่าน `api.command` ของโรงเรียน) และ `Local CLI Context Mode` (รันผ่าน CLI ของระบบจริงใน LXC container)
3. **การออกแบบ CLI Interface**: กำหนดขอบเขตความรับผิดชอบและการรายงานสถานะผ่านคำสั่งมาตรฐาน `say` และ `status` เพื่อทำงานร่วมกันในสภา

## บทที่ 3: Lessons Learned (บทเรียนที่ได้รับ)

1. **การจัดการ Cache และ Storage**: การรันโปรเจกต์จำนวนมากในสภาพแวดล้อม CLI อาจทำให้เกิดปัญหาดิสก์เต็มหรือเกิด Watchdog loop ได้ง่าย จึงควรมีการบีบอัดหรือจำกัดขนาดไฟล์ชั่วคราวอย่างสม่ำเสมอ
2. **ความยืดหยุ่นและการทำงานแบบประสานงาน (Resilience & Coordination)**: การส่งต่อสาร (Delegation) ของทีมบอทผ่านช่องทางหลังบ้านและการสังเกตการณ์สถานะการค้างจากตัวดูแลระบบหลังบ้าน (No.10) ช่วยให้สามารถสแกนหาข้อผิดพลาดและกู้คืนบอทให้กลับมาทำงานต่อได้อย่างรวดเร็ว
